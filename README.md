# Webapp-using-Flask-and-Gpt4all
Webapp using Flask and Gpt4all. Disclaimer: This project was created for learning and demonstration purposes only. It is not intended for production use

The Goal of this little project is to build a simple webapp using Flask and and Gpt4all. 
After several attempts I could not pursue the approached of building the app using Gpt4all Falcon direct model ( due to http error). 
So my work arround was to allow local api within Gpt4all application and used the local host URL to accomplice the project. 
Overall to make it works you need python, HTML, and Gpt4all Falcon (installed on your desktop).
